# List the library (capability)

Inspect available **Door** or **Window library parts** in Archicad.

There are two different inventories:

* **Placeable now** — loaded library parts and saved Favorites available from the Door/Window Settings dialog.
* **Available in the library** — additional parts visible through Library Manager.

This is a **read-only** capability.

Do not load, remove, replace, or modify any library part.

## A. Placeable now — Settings part browser

Use this first to see which Door or Window parts are already available for placement.

1. Activate the required tool:

   * **Door**, or
   * **Window**

2. Open the tool's **Settings** dialog.

3. Inspect the library-part browser in the upper part of the dialog.

   It contains:

   * folder/category tree;
   * thumbnail or item list;
   * search field;
   * selected part preview and name.

4. Browse the available parts or use the **Search** field to find a specific name.

5. When a part is selected, read its **full exact name** from the dialog.

   Do not rely only on a thumbnail, because visually similar parts may have different names.

6. Scroll or change folders as needed to inspect additional loaded parts.

> ⚠️ Only parts visible in this Settings browser are immediately available to the active Door or Window tool.

## B. Placeable now — Favorites

Saved Favorites are reusable presets stored with the project.

1. While the Door or Window Settings dialog is open, locate the **Favorites** control, shown with a **star icon**.

2. Open the Favorites list.

3. Read the available Favorite names exactly as shown.

4. Do not select/apply a Favorite when only inspecting the list.

5. Close the Favorites list when finished.

> ⚠️ A Favorite is a saved preset, not necessarily a unique library part. Do not confuse Favorite names with the underlying Door or Window part names.

## Close the Settings dialog

After inspecting loaded parts and Favorites:

1. click **Cancel**;
2. return to the Floor Plan.

Use **Cancel**, not OK, because this capability is read-only.

> ⚠️ Clicking **OK** can leave the currently highlighted part/settings as the active tool default.

## C. Browse additional Door parts

Use this only when the required Door is not found among the currently placeable parts.

1. Open **Library Manager**: **File > Libraries and Objects > Library Manager…**.

2. Inspect the loaded library structure.

3. Expand the relevant library folders and browse the **Door / Doors** groups.

4. Read the available part names exactly as displayed.

5. Scroll or expand subfolders as required.

6. When finished, click **Cancel**.

> ⚠️ This is inspection only. Do not remove libraries, add libraries, reload libraries, or change library configuration.

> ⚠️ Do not open an Add/Browse workflow merely to inspect files. Use the existing Library Manager tree.

## D. Browse additional Window parts

Use the same process for Windows.

1. Open **Library Manager**.
2. Browse the relevant **Window / Windows** groups and folders.
3. Read the available part names exactly as displayed.
4. Scroll or expand subfolders when necessary.
5. Click **Cancel** when finished.

Do not make any library changes.

## Important distinction

Keep these inventories separate:

* **Settings part browser** → loaded parts that can be placed now;
* **Favorites** → saved project presets;
* **Library Manager** → library content and structure available beyond the active tool browser.

A part visible somewhere in the library is not automatically equivalent to a currently selected or saved Favorite.

Always record the **exact displayed name** before closing the dialog.

## Verification

The names you report are exactly the on-screen ones, from the inventory the
instruction asked about, and nothing was loaded or changed — report nothing else.
